Welcome to my DevOps project! This web application is containerized with Docker, published to Docker Hub, and deployed to a local Kubernetes cluster using GitHub Actions.

Version 2 — Automatic Deployment Test
🐳

Docker

Packages the web application into a portable container image for consistent deployment.

⚙️

GitHub Actions

Automatically builds, tests, and publishes a new image when changes are pushed to the main branch.

☸️

Kubernetes

Runs and manages application replicas inside the local Kind Kubernetes cluster.

📦

Docker Hub

Stores versioned container images that the deployment pipeline can use.

CI/CD Pipeline Stages

1. ✓ Code Push changes to GitHub
2. ✓ Build Build the Docker image
3. ✓ Test Verify the web application responds
4. ✓ Publish Push the image to Docker Hub
5. ✓ Deploy Update the Kubernetes Deployment
Built as a hands-on DevOps learning project using Docker, GitHub Actions, Docker Hub, and Kubernetes.
